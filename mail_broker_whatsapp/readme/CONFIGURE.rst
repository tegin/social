First steps
~~~~~~~~~~~~~~

1. Read the documentation <https://developers.facebook.com/docs/whatsapp/cloud-api>
2. Create or use an existing FB account to create a Business Manager <https://developers.facebook.com/docs/whatsapp/cloud-api/get-started-for-bsps>
3. Create an Whatsapp Business account (WABA) <https://www.facebook.com/business/help/2087193751603668?id=2129163877102343>
4. Create a Meta Application (Business role) with Advanced Access following <https://developers.facebook.com/docs/app-review/resources/sample-submissions/whatsapp-business-api>
5. Add system users to Business Manager <https://www.facebook.com/business/help/503306463479099?id=2190812977867143>
6. Company Number to send messages (need to be verified)
7. Consumer Number (receives the company messages)
8. Accept WhatsApp Business Platform Terms of Service
